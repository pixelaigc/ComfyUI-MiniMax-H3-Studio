### 3.2 缺陷 2 —— SSE 失败路径丢失「重试」入口（P1）

| 项 | 内容 |
|---|---|
| **现象** | 真实浏览器：Agent 执行失败时**红色错误条正常显示，但「重试」按钮消失** |
| **根因** | 服务端把 Agent 执行失败发成 **SSE `error` 事件**（HTTP 200）或 **`done` 事件里 `status=failed`**（HTTP 200）。两者都不抛错 → 前端 `send()` 走进「成功」分支 → 该分支无条件执行 `msg.retryRequest = null`（`web/agent.js`）→ `renderError` 里 `canRetry = !!msg.retryRequest` 为假 → 按钮不渲染 |
| **影响面** | 用户看到失败却没有一键重发的入口，只能手打一遍原话。已有用例 `test_failure_shows_error_and_retry_button` 只覆盖 **HTTP 500**（`fetch` 抛错 → `catch` 分支 → `retryRequest` 被保留），抓不到这条路径 —— 所以缺陷能长期存活 |
| **修法** | 只有**真成功**才清 `retryRequest`：判据 = 无 `error` 字段 **且** `status` 不是 `failed`/`error`/`aborted`（`needs_clarification` 不算失败 —— 那是正常追问，要保留重试入口） |
| **新增回归** | `test_sse_error_event_keeps_retry_entry`（SSE error 事件后必须同时有错误条和重试按钮）<br>`test_sse_done_failed_keeps_retry_entry`（done(status=failed) 同上）<br>`test_successful_message_has_no_retry_entry`（**反向判据**：成功的消息不许挂重试按钮） |
| **变异验证** | 把修复改回「无条件清」→ 2 failed；恢复修复 → 4 passed |
| **缓存联动** | `web/agent.js` 内容变了 → `index.html` 里 `?v=` 必须再升：`cr20261115b` → `cr20261116b`（漏升 = 老缓存用户拿不到修复；本仓库第 3 轮收口已因同类问题踩过坑，提交 `6de4a42`）<br>同步更新 `tests/test_frontend_assets_hygiene.py` 的 `STALE_BUMPED` 清单 |
| **结果** | `tests/test_agent_frontend_enh.py`：31 passed → **34 passed** |

### 3.3 缺陷 3 —— 三个 Agent 接口缺「请求体必须是对象」检查（P2）

| 项 | 内容 |
|---|---|
| **现象** | `POST /api/agent/chat`、`POST /api/agent/chat/stream`、`POST /api/agent/memory` 传**合法 JSON 数组**（`[1,2]`）→ **HTTP 500**，响应体是 aiohttp 的默认错误页（不是本项目 JSON 契约），且**把 Python 栈信息泄给客户端** |
| **根因** | 这三个端点缺 `isinstance(payload, dict)` 检查 → `payload.get(...)` 对 list 抛 `AttributeError` → 冒泡到 aiohttp 兜底处理器 |
| **对照** | 同批的 `PUT /api/agent/settings`、`POST /api/agent/settings/test-engine`、`POST /api/agent/sessions` **都有**这道检查并返回 400 —— 只有这三个漏了 |
| **修法** | 三处补 `isinstance(payload, dict)` → 返回 400 + `{"error": "请求必须是对象", "code": "bad_request"}` |
| **新增回归** | `TestNonObjectPayloadContract` 6 条：三个 chat/memory 端点各自拒数组/字符串 + 一个**对照项**（settings 行为一致）+ 一个**反向项**（sessions 的 body 可选，传非对象按空 body 处理，属既有契约不改） |
| **变异验证** | 修复前实测 3 failed（错误信息含 `AttributeError: 'list' object has no attribute 'get'`）；修复后 6 passed |
| **结果** | `tests/test_agent_contract.py`：27 passed → **31 passed** |
