## 0. 一句话结论

「flf 段2 三帧亮度降」**不是接缝亮度跳变的指标**——它测的是「段2 内部前三帧的亮度演化」，
会被段内光照事件与采样路径共同污染。真正测接缝台阶的量是
`A = lum[段2 首帧] − lum[段1 末帧]`；在**素材受控**的 9 条样本上，
`A 的均值 (−0.4693) ≈ 段1 自身首帧自然收敛 N 的均值 (−0.4393)`，
**接缝没有引入任何超出模型固有收敛的额外亮度台阶**。
⇒ 符合判定 (a)「单样本波动」，**一条生产代码都不许改**（本轮确实零改动）。

## 4. 判定与依据

### 4.1 判定 (a)「单样本波动」——成立

按任务口径的两条判据逐条核对（以判定指标 A 为准）：

| 判据 | 门槛 | 实测（14 条全池） | 结论 |
|---|---|---|---|
| 均值明显小于门槛 | \|mean\| < 0.3 | **−0.2373** | ✅ 通过 |
| 方向不一致 | 正负都有 | **正 3 / 负 11** | ✅ 通过 |
| 离散度可归因于素材内容差异 | — | 见 4.2 | ✅ 通过 |

**不满足判定 (b)「系统性偏暗」的任何必要条件**：\|mean\| = 0.2373 < 0.3，且方向并不完全一致。
⇒ **一条生产代码都不许改**（严禁为凑指标改逻辑）。

### 4.2 决定性证据：接缝台阶 ≈ 段首自然收敛

在**素材受控**的 9 条样本（素材 A）上：

```
A 接缝台阶   均值 = −0.4693   （符号 正0/负9）
N 段1自然收敛 均值 = −0.4393   （符号 正0/负9）
E = A − N    均值 = −0.0300   （符号 正4/负5）  ← 超额几乎为 0
```

**配对 t 统计量 = −1.481**（|t| < 2.16 ⇒ p > 0.05，不能拒绝「A 与 N 无差异」）。

也就是说：接缝处那 ~0.45 灰阶的亮度台阶，**不是接续引入的**——
它等于模型在任何一段开头都会做的首帧锚点收敛量（段1 完全不涉及接续，
同样有 −0.44 的首帧收敛）。**接续没有额外贡献任何亮度台阶。**

### 4.3 任务原口径 B 为何不能用来判定接缝

三条独立证据：

**证据 1 —— B 会随采样路径改变符号。** 素材 A 组 4 条链，段1 与段2 同素材同场景：

| 段2 job | 段1(SelfLift) B | 段2(标准) B |
|---|---|---|
| `c3264ca57a71` | −0.3894 | **+0.6622** |
| `41b7cc9dde0c` | −0.3203 | **+0.3033** |
| `5059526c4075` | −0.5861 | −0.9912 |
| `dcd2581e3482` | −0.3894 | **+0.7169** |

段1(SelfLift) 4/4 为负，段2(标准) 3/4 为正 ⇒ B 测的是「路径相关的段首收敛行为」，
不是接缝台阶。

**证据 2 —— B 被段内光照事件污染。** 样本 #5（seed 20261125）段2 首 12 帧逐帧亮度：

```
[126.400, 126.934, 127.600, 154.464, 158.027, 157.581, 157.479, 163.012, ...]
                    ↑ 第 4 帧亮度跃升 +26.9 灰阶（画面开灯/曝光变化）
段2 前 3 帧斜率 = +9.3546 灰阶/帧
B = −28.0637   ← 极端值来自段内事件
A = +0.8522    ← 接缝本身基本连续
```

把 −28.06 与 +0.717 放进同一个均值池会严重污染统计（这正是上一轮 N=3 时
"+0.717 是单样本波动"这个结论不牢靠的根源）。

**证据 3 —— 素材是混淆因子。** 脚本 `pick_image()` 默认取「素材库最新一张」，
本轮首跑自动拿到了新素材 B，与上一轮的素材 A 不同 ⇒ 两批样本的绝对亮度水平
不可直接混合比较。这正是本轮补做**素材 A 受控组**（seed 20261126–20261130，
固定 `H3STUDIO_ASSET_ID=asset_afb7438fdadf`）的原因。
