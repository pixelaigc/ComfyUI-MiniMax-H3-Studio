### 2.2 冲突预检（带对照组）

`git merge-tree --write-tree` 退出码 0 只在「能报冲突」的前提下才有意义，因此做了**对照组**：

```
# 对照组：造一个真 3 路冲突（同一处改成不同内容）
$ git merge-tree --write-tree tmp/conflict-ours tmp/conflict-theirs
exit=1                          ← 工具确实能报冲突

# 正题：本次要合的分支
$ git merge-tree --write-tree local/maintainer local/feature/agent-ui-fix
exit=0                          ← 现在这个 0 才有意义 = 真无冲突
```

> 对照组用的 `tmp/conflict-*` 临时分支在验证后已全部删除
> （`git branch -a | grep tmp/` → 无输出）。
