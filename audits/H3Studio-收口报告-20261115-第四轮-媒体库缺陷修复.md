## 【新增缺陷】生成媒体库只有视频条目，看不到文生图/音频产物

**结论：有缺陷 -> 已修复并上线（commit `2839079`）。**

### 只读定位（三个根因，都已线上复现；不是落盘/索引问题）

**先排除「落盘/索引」**（这一层是好的）：
- `jobs.db` 里 image / audio / video 三类产物**都真实落盘**且 `outputs` 带 `kind`：
  `t2i -> images/i-zimage-000180.png (kind=image)`、`i2i_qwen -> images/i-zimage-000181.png`、
  `t2i_moss -> images/i-zimage-000182.png + i-zimage-000183.png`（同任务多批次）、
  `t2a -> audio/a-yue2-000051.flac (kind=audio)`、`t2v -> videos/v-h3-studio-000241.mp4`。
- `GET /api/jobs?status=all&page_size=400` -> `total=406`，modes 里 t2v32/flf26/r2v28/t2i6/t2i_moss4/i2i_qwen2/longfilm1/t2a1 **全都在**。
- 前端卡片渲染层正常：图片卡渲染 `<img src="/files/images/...">`、视频卡渲染 `<video>`；多批次任务渲染出 2 张图。
- **有批次与无批次两条路都通**（多批次任务 `633923eaec4a` 渲染出 2 张图）。

**根因 1（用户看到「只有视频」的**直接原因**，前端筛选状态粘滞）**
- 代码：`web/app.js::showStitch()` 里写死了
  `state.doneFilters.media = "video"; $("#doneMedia").value = "video";`
- 那是给「长片拼接」页用的**局部**筛选（拼接只收视频片段），但写进了**全局**筛选状态
  `state.doneFilters` + DOM 控件 `#doneMedia`。`state.doneFilters` 是模块级单例；
  `renderTabs()` 只切 tab 高亮与 `#doneFilters` 显隐、`showCreate()` 也不碰它；
  `refreshJobs()` 直接读它拼 query —— 于是筛选**永久粘滞**。
- **线上复现（修复前）**：① 新开页点「生成」-> 12 张卡含 5 张图；
  ② 点左侧「长片拼接」-> `#doneMedia` 变成 video -> 12 张全是视频；
  ③ 再点「生成」回到媒体库 -> `#doneMedia` **仍是 video** -> 图片全部消失。

**根因 2（后端 media 维度缺 audio）**
- `server.py::api_list` 的 media 分支只有 image / video / longfilm，`media=audio` 落到
  `elif media:` 直接 **400**（"media 只能是 image、video 或 longfilm"）。
- 而 `gen_types` 注册表里 `t2a`（文生音乐）/ `a2a`（参考生音乐）的 `media` **就是 audio** —— 没有任何分支消费它。

**根因 3（前端下拉缺「音频」）**
- `web/index.html` 的 `#doneMedia` 只有「全部类型/视频/图片」，没有「音频」。

### 修复（修数据源/过滤逻辑本身，未删改任何既有条目）

1. `showStitch()` 不再写全局 `doneFilters` / `#doneMedia`，改用**页面级** `state.stitchMediaOverride`；
   `refreshJobs()` 只在 `state.page === "stitch"` 时把它临时叠加到 query；`showCreate()` 离开该页时清空。
   → 长片拼接页仍然只看视频（该页行为不变），但不再污染全局筛选。
2. `server.py::api_list` 的 media 分支统一成 `media in ("image", "video", "audio")`，
   按 `gen_types` 注册表推导 mode 列表（与 image/video 同一套推导，新增模式不会再被漏掉）；
   错误文案改为「image、video、audio 或 longfilm」。
3. `web/index.html` 的 `#doneMedia` 补 `<option value="audio">音频</option>`。
4. 升 `app.js?v=mediadef1`（仓库纪律：改 app.js 必须升版号破浏览器缓存）。
