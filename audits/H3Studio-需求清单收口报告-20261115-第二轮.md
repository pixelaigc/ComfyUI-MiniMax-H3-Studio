## B2 参考生视频：≤9 参考图 + N 视频 + 1 音乐；音轨三选一

**结论：已上线可用**（本轮修了一个真实的前端缺陷，已上线并现场复核）。

### 本轮发现并修复的缺陷（线上实测）

**现象**：参考生视频面板里，从「参考音乐 1」槽位的「素材库」选一段音频并「确定使用」后，`audioTrackAvailability()` 已返回 `hasRefAudio=true`，但 `#audioTrackSelect` **仍只有 1 项**（只有「使用生成的音乐」）；手动调 `window.renderAudioTrackSelect()` 之后立刻变 2 项。

**影响**：B2「音轨三选一」里的「使用参考音乐作为成片音轨」与「使用参考视频的背景音乐」这两项，**在真实用户路径上永远出不来**（选完素材不刷新，只有切模式才刷新）。

**根因**：`web/app.js` 的 `fillFromAsset` / `fillSlot` 改完 `state.assetRefs` / `state.files` 之后**没有**调用 `renderAudioTrackSelect()`；而该函数只在切换模式（`app.js:689`）与下拉自身 change（`app.js:858`）时被调用。

**修复**：`ad66ae4 fix(b2): 素材库填入参考音乐/参考视频后立刻重算音轨来源下拉` —— 两处填槽位路径各补一次 `renderAudioTrackSelect()`（带 `typeof` 守卫）。
配套 `242e639 chore(b2): 升 app.js 版号到 b2audiotrack1` —— 仓库自己写明的纪律（`index.html:1570` 注释）：改 app.js 必须升 `?v=` 版号破浏览器缓存，否则用户拿到的还是旧文件。

### 上线后现场复核（本轮 round2 实测）

| 步骤 | 现场读数 |
|---|---|
| 进入参考生视频（无参考素材） | 下拉 = `['']`（只有「使用生成的音乐」） |
| 素材库选参考音乐 → 确定使用 | 下拉 = `['', 'reference']` ✅ 自动出现，无需手动刷新 |
| 再素材库选参考视频 → 确定使用 | 下拉 = `['', 'reference', 'video_bg']` ✅ **三选一齐全** |

服务端真源（`h3studio/h3_audio_track.py`）本轮直接跑了一遍：
`available_track_sources(False,False)=['generated']` / `(True,False)=['generated','reference']` / `(True,True)=['generated','reference','video_bg']`；`normalize_track_source('reference',False,False)='generated'`（选了但无素材 → 回落，不报错）。
